# spec/ — what we build, written before we build it

Status: frozen, {{date}}. Authority above it: `CHARTER.md`.

One file per component or protocol, named for the thing (`scoring.md`,
`intervention.md`). Each opens with `Status: proposed | frozen | superseded`
and an absolute date. Once frozen, a spec changes only by a dated revision
note at the bottom. Code with no spec is a probe: it lives in the package
with a dated changelog note and is not trusted for paper numbers.

Write `scoring.md` first.
