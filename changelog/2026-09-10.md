# Changelog — 2026-09-10

## 2026-09-10 — checkpoint 3: venues (unreleased, toward 0.3.0)

- `rharness venue`: add, status, change, lock, unlock, check, update, remove,
  list. One venue per project, stored in `.rharness/project.json`; every
  transition appends a dated line to `CHARTER.md`.
- Venue packages under `venues/` in this repository, excluded from the
  release tarball, fetched on demand with a 24-hour refresh. Metadata in
  `venue.json`, validated by `scripts/venues-validate.py`; `INDEX.json`
  generated; weekly source-page watch opens an issue on change.
- Generic venue checks in `venuecheck.py`: page count against the main-body
  limit, required sections, citation keys, style loaded, anonymity. Package
  `checks.py` optional. Findings are warnings until `venue lock`.
- `rharness paper build`: latexmk via the scaffold Makefile with a `tlmgr`
  missing-package loop; TinyTeX suggested by `doctor` when no engine exists.
- `pdfutil`: page count without poppler (object streams inflated), text via
  `pdftotext` when present.
- `doctor` gains a note state for optional tools. Manifest region entries may
  carry a region name. Scaffold: `% rharness:venue-style` marker, Makefile
  rebuilds on style changes, `paper/main.pdf` gitignored.
- First package: `iclr2027`.
