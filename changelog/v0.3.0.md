# rharness 0.3.0 — venues

Released 2026-10-07. The day-by-day record is in [2026-09-10.md](2026-09-10.md)
and [2026-10-07.md](2026-10-07.md).

## New

1. **Venues.** `rharness venue add|status|lock|unlock|change|check|update|remove|list`
   attaches a submission target to a project. Packages come from `venues/`
   in this repo and refresh after 24 hours. The first package is `iclr2027`.
2. **Venue checks in lint:** page limit, required sections, citation keys,
   style file, and anonymity. Findings are warnings until `venue lock`.
   Lint also warns about passed or close deadlines and a missing or stale PDF.
3. **Lint any LaTeX repo against a venue:** `rharness lint --venue iclr2027 dir`,
   with no rharness setup. `--main FILE` picks the main file.
4. **`rharness paper build`** builds `paper/main.pdf` with latexmk and
   installs missing TeX packages through `tlmgr`.
5. **Bibliography checks:** unknown cite keys, duplicate keys, malformed
   entries, the same DOI under two keys, and uncited entries.
6. **`fail_on`** in `lint.toml` (or `--fail-on error`) makes lint fail on
   errors only.
7. **Word caps** on CHARTER.md (600), the newest handoff (600), the last
   changelog entry (400), and the brief (1500). Over the cap is a warning,
   over twice the cap is an error, and `0` turns a cap off.

## Changed

8. `brief` shows the venue and its deadlines.
9. `doctor` lists optional tools as notes and suggests TinyTeX when no TeX
   engine is found.
10. `\cite` matching covers the natbib and biblatex forms (`\citet`,
    `\parencite`, `\nocite`, ...).
11. The paper scaffold gains a venue-style marker in `main.tex` and a
    Makefile that rebuilds on style changes; `writing.md` gains a
    read-aloud test.
12. External venue packages ask before installing, because their
    `checks.py` runs during lint.
13. The README is shorter. `ISSUES.md` and issue forms describe how to file
    issues.

## Upgrading

Run `rharness update`. Existing `lint.toml` files keep working, and lint
still exits 1 on any finding by default. Lint may show new bibliography and
word-cap warnings; raise a cap in `lint.toml` or set it to `0`.
