# Changelog — 2026-09-09

## 2026-09-09 22:20 CDT — checkpoint 1: v0.1.0

- First release. `init`, `new`, `adopt`, `add`, `remove`, `list`, `lint`,
  `doctor`, `update`, `version`. Python 3.9+ stdlib, `install.sh` bootstrap.
- Base content distilled from a working research workspace: root `AGENTS.md`
  with a managed region, project scaffold (charter, orientation, specs,
  writing guide, LaTeX skeleton, handoff and changelog conventions), eleven
  document archetypes.
- Managed-file model: every written file hashed in a manifest; `update`
  replaces only unmodified files and rewrites only marked regions.
- Plugins: `rtk` (default), `figures`, `review-panel`, `wandb`, `ideas`.
- 105 tests; CI on macOS and Ubuntu, Python 3.9 and 3.13.
- Not yet done: external plugin sources, session orientation, provenance.

## 2026-09-09 23:55 CDT — checkpoint 2: v0.2.0

- Plugins from outside the release: `add` accepts a local path, a git URL,
  or `owner/repo[/subdir]`, with `@ref` pinning to a tag, branch, or commit.
  External plugins print a capability summary (files, `AGENTS.md` section,
  skills, every hook command, `setup.sh`, requirements) and require
  confirmation or `--yes`. `plugin new` scaffolds a plugin. `plugin.json`
  gains `requires.env`, reported after install. `docs/plugins.md`.
- Session orientation: `brief` prints the charter status, newest handoff,
  last changelog entry, authoritative docs, provenance count, and lint
  findings; workspace table at the root. Projects get `CLAUDE.md` and a
  managed region in `AGENTS.md` with the session protocol and workspace
  rules, inserted into existing projects on adopt.
- Claude Code session hooks shipped in the base and merged by `init` and
  `adopt`: SessionStart injects `brief`; Stop runs `session-check`, which
  blocks finishing on a day with work but no handoff and changelog.
  `doctor` verifies both.
- Provenance: `research/PROVENANCE.md` per project and `hash` to record
  frozen artifacts with sha16, size, date, and code commit. Lint errors when
  a recorded file changes or disappears, warns on unrecorded traces.
- Lint checks the contract, not only the structure: kill criterion must
  state a threshold, `spec/scoring.md` must keep its control and ceiling
  rows and be frozen before experiment reports exist, source code needs a
  component spec. Lint output and `brief` say so: structure and contract
  fields, not the science.
- Verified releases: `scripts/release.sh` builds the tarball from git and
  publishes it with `SHA256SUMS`; `install.sh` and `update` verify the
  download and refuse on mismatch or missing sums (`RHARNESS_INSECURE=1`
  overrides).
- Fixes: CI failed because test commits ran without a git identity on
  GitHub runners; bare plugin names were mistaken for local paths once their
  files existed; hyphenated subcommands did not dispatch.
- Site at `web/`, deployed by GitHub Pages: Why, Opinions, Plugins.
- 157 tests.
