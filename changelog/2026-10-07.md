# Changelog — 2026-10-07

## 2026-10-07 — checkpoint 1: severity-aware lint exit (unreleased, toward 0.3.0)

- `lint.toml` gains `fail_on` (`warning` by default, or `error`), and
  `rharness lint` gains `--fail-on`, which overrides it. Under `error`,
  warnings still print but lint exits 0, so a targeted venue stops failing
  lint and a locked one fails on its errors. Default behaviour is unchanged.
  An unknown `fail_on` value exits 2 before any check runs.
