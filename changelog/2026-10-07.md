# Changelog — 2026-10-07

## 2026-10-07 — checkpoint 1: severity-aware lint exit (unreleased, toward 0.3.0)

- `lint.toml` gains `fail_on` (`warning` by default, or `error`), and
  `rharness lint` gains `--fail-on`, which overrides it. Under `error`,
  warnings still print but lint exits 0, so a targeted venue stops failing
  lint and a locked one fails on its errors. Default behaviour is unchanged.
  An unknown `fail_on` value exits 2 before any check runs.

## 2026-10-07 — checkpoint 2: `lint --venue` on a bare LaTeX directory

- `rharness lint --venue <name> [dir] [--main FILE]` runs the venue checks
  on a LaTeX directory with no rharness files. The main file is `main.tex`
  or the one `\documentclass` file; tex sources follow `\input`,
  `\include`, `\subfile`; bib files come from `\bibliography` /
  `\addbibresource`; the PDF is the main file's name with `.pdf`.
  Severity is as returned. A foreign source needs `--yes`; a stale cache is
  re-fetched, with the cached copy used when that fails.
- `venuecheck` generic checks take a layout. Project findings are
  unchanged.

## 2026-10-07 — checkpoint 3: bibliography checks

- `bibcheck.py`: BibTeX parser (braces, quotes, `#` concatenation,
  `@string`/`@comment`/`@preamble` skipped) and checks for malformed
  entries (not closed, no key, unreadable fields, no title), the same DOI
  under two keys (`https://doi.org/` and `doi:` forms normalised), and
  uncited entries (one summary warning; skipped with `\nocite{*}`).
- Citation matching covers `\citet`, `\citep`, `\parencite`, `\textcite`,
  `\nocite`, and the other natbib/biblatex variants.
- Runs in the venue generic set and, every finding a warning, in project
  lint when the project has no venue and has `paper/references.bib`.

## 2026-10-07 — checkpoint 4: word caps on orientation files

- `lint.toml`: `charter_max_words` (600), `handoff_max_words` (600),
  `changelog_entry_max_words` (400, the last `## ` entry of the newest
  changelog file), `brief_max_words` (1500, `rharness brief` without its lint
  section). Over the cap is a warning, over twice it an error; `0` disables.
  HTML comments do not count. Defaults are provisional until measured on a
  dogfood project.
- `brief.project_brief` gains `include_lint` so lint can size the brief
  without recursing.
