# rharness 0.3.1 — NAACL 2027 and ACL 2027

Released 2026-10-07. The day-by-day record is in [2026-10-07.md](2026-10-07.md)
(checkpoint 5).

## New

1. **NAACL 2027** (`rharness venue add naacl 2027`): ARR October 2026 cycle.
   Submission is due 2026-10-12 and commitment 2026-12-23, both AoE.
2. **ACL 2027** (`rharness venue add acl 2027`): ARR January 2027 cycle.
   Submission is due 2027-01-04 AoE. The commitment date isn't announced yet.
3. Both packages use the official ACL style files and check the 8-page
   long-paper limit and the required Limitations section. They warn when
   `acl` is loaded without `[review]`, and the playbook includes the ARR
   review form.

## Fixed

4. **Page limit with ACL line numbers:** in review mode, no heading was
   found, so the whole PDF counted as the main body. Headings are now read
   in reading order.
5. **A heading at the top of a page:** Limitations or References opening
   page 9 now means an 8-page body, not 9.
6. **Author block hidden by the style:** `\author{}` is no longer flagged
   when the style hides it, as with `\usepackage[review]{acl}`, or ICLR
   without `\iclrfinalcopy`.
7. `venue add` now names the exact style line, e.g.
   `\usepackage[review]{acl}`.

## Upgrading

Run `rharness update`. This release fixes false page-limit and author-name
errors on ARR papers that are formatted correctly.

## Known issues

Short papers (4 pages) are checked against the 8-page long-paper limit.
#10–#14 are still open.
